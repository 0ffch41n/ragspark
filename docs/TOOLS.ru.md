# Инструменты

[English version](TOOLS.md)

Самостоятельные скрипты на Python для настройки и проверки стека RAGSpark. Им
не нужно ничего, кроме стандартной библиотеки Python. Три из них запускаются
*внутри* контейнера RAGFlow: оттуда сервисы vLLM доступны по имени, есть
собственное шифрование пароля RAGFlow, а данные суперпользователя и настройки
LLM уже лежат в окружении контейнера (`compose/.env` и файл LLM).

Команды ниже выполняются из каталога `compose/`.

## ragflow_models.py — регистрация моделей в RAGFlow

Регистрирует обслуживаемые vLLM модели — LLM, эмбеддинги и реранкер — в учётке
администратора RAGFlow и назначает их моделями по умолчанию. Повторный запуск
ничего не меняет.

```bash
# только проверка
sudo docker compose exec -T ragflow \
  sh -c 'cd /ragflow && PYTHONPATH=/ragflow .venv/bin/python - --check' < ../tools/ragflow_models.py
# применить
sudo docker compose exec -T ragflow \
  sh -c 'cd /ragflow && PYTHONPATH=/ragflow .venv/bin/python -' < ../tools/ragflow_models.py
```

Запись для LLM берётся из `RAGSPARK_LLM_NAME`, `RAGSPARK_LLM_CONTEXT` и
`RAGSPARK_LLM_TOOLS`, которые выбранный файл LLM задаёт сервису RAGFlow;
`--spec ФАЙЛ` заменяет весь список.

| Статус | Значение |
|---|---|
| `[OK]` | уже как нужно |
| `[TODO]` | будет изменено (только в `--check`) |
| `[SET]` | модель по умолчанию назначена или переназначена |
| `[FAIL]` | требует внимания; код выхода 1 |

Существующие экземпляры не изменяются никогда. Если экземпляр указывает на
другой адрес, скрипт сообщает об этом и не трогает его. Модель по умолчанию,
ссылающаяся на удалённую модель — так бывает после удаления и пересоздания
экземпляра, — обнаруживается по идентификатору и переназначается.

## rag_eval.py — качество разбора и поиска

Только читает. Для каждого документа базы знаний показывает число фрагментов,
долю кириллических букв и число искажённых слов — латинских двойников вроде
`Pa3beM`, которые даёт распознавание, не знающее кириллицы. Затем прогоняет
набор вопросов через API поиска в пяти настройках и проверяет, найден ли
фрагмент с ожидаемыми фактами.

```bash
sudo docker compose exec -T ragflow \
  sh -c 'cd /ragflow && PYTHONPATH=/ragflow .venv/bin/python - --dataset test' < ../tools/rag_eval.py
```

| Ключ | Что делает |
|---|---|
| `--dataset ИМЯ` | какую базу знаний проверять (по умолчанию `test`) |
| `--questions ФАЙЛ` | JSON-список `{"q": ..., "expect": [...]}`; `"expect": null` — вопрос, ответа на который в документах нет |
| `-v` | показать примеры искажённых слов |
| `--why` | для не найденных вопросов повторить поиск с порогом 0 и показать, на каком месте ответ |
| `--probe` | для не найденных вопросов оценить фрагмент с ответом напрямую реранкером в нескольких видах |

Обозначения: `#N` — место первого фрагмента с ожидаемыми фактами; `miss` — нет
в первых N; `none` — ничего выше порога; `ok` — на вопрос без ответа правильно
ничего не найдено; `LEAK` — на вопрос без ответа что-то нашлось (показана
лучшая оценка).

Встроенный набор вопросов составлен по русской инструкции к материнской плате
MSI MPG B550 Gaming Plus (фрагмент на 39 страниц). Сама инструкция в RAGSpark
не входит; для других документов используйте `--questions`.

## model_probe.py — язык и скорость LLM

Задаёт LLM русские вопросы в трёх режимах — с рассуждениями, без них и без них
с температурой 0,7 — и показывает скорость и сколько ответов содержат
китайские, японские или корейские символы.

```bash
sudo docker compose exec -T ragflow /ragflow/.venv/bin/python - < ../tools/model_probe.py
# любой OpenAI-совместимый сервер:
VLLM_URL=http://host:8000 MODEL=<имя модели> python3 tools/model_probe.py
```

## pin_images.py — закрепление образов хешем

Запускается на хосте. Для каждой строки `image:`, где указан только тег,
записывает хеш локального образа из реестра (`имя:тег@sha256:…`); уже
закреплённые строки сверяет с локальным образом. Нужен после смены тега и
скачивания нового образа.

```bash
sudo python3 tools/pin_images.py compose/compose.yaml compose/llm/*.yaml          # закрепить
sudo python3 tools/pin_images.py --check compose/compose.yaml compose/llm/*.yaml  # только отчёт
```
